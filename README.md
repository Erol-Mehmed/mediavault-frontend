# MediaVault Frontend

MediaVault frontend application built with Next.js.  
This project is the UI layer for the MediaVault ecosystem and communicates with the MediaVault API.

## Tech Stack

- Next.js
- TypeScript
- Redux Toolkit
- SCSS

## Features

- Authentication (login / logout / refresh)
- Media dashboard (movies, TV shows, games, anime)
- Add / edit / remove media items
- User-specific media collections
- API integration with backend service
